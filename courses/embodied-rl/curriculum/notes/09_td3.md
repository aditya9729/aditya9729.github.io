# 10 · TD3: why two critics are only the first change

### Three changes address three coupled failure modes
TD3 extends the deterministic actor–critic pattern with clipped double Q targets, delayed actor/target updates, and target-policy smoothing. Learning only “use two critics” misses most of the algorithm. Each change addresses a different way that an actor can overfit critic errors.

Two critics are trained on the same replay data with separate parameters. Their minimum is used in the target to reduce the tendency to bootstrap from an overoptimistic prediction. The critics are correlated estimators, not independent votes. Taking a minimum can introduce underestimation; it is a conservative bias tradeoff rather than an unbiased truth detector.

The actor is updated less frequently than the critics. This gives value estimates more opportunity to respond before the actor moves again. The target actor and target critics typically update on that delayed schedule too. Be precise about whether a reported “update ratio” counts critic optimizer steps, actor optimizer steps, or total transitions. They are not interchangeable quantities.

Target-policy smoothing adds clipped noise to the target actor's action before evaluating the target critics. It encourages values that are less dependent on a single sharp action spike. It is not the same noise used for exploration in the environment. A target-noise setting that is sensible in normalized [-1,1] units may be nonsensical if accidentally interpreted as radians or actuator force.

### What you should log besides reward
Inspect each critic's scale, their disagreement, target values, and action saturation. A falling critic loss may only mean the online critics match a bad bootstrap target. A small actor loss can mean Q values are large, not that physical behavior is good. Compare predicted returns with measured returns on fixed evaluation resets.

The original code in this course makes the two schedules and two noise sources explicit. It uses compact MLPs and a single Gymnasium environment to make updates inspectable. FastTD3's scale and systems choices are a later research layer; this implementation is not a reproduction of its distributional critics, massive parallelism, or performance claims.

### Derivation: the clipped target
Construct the noisy bounded target action
$$\tilde a=\operatorname{clip}(\mu_{\bar\theta}(s')+\operatorname{clip}(\epsilon,-c,c),-1,1),\quad \epsilon\sim\mathcal N(0,\sigma^2I).$$
Then
$$y=r+\gamma(1-d)\min_{i=1,2}Q_{\bar w_i}(s',\tilde a),\qquad
L_Q=\sum_i\mathbb E[(Q_{w_i}(s,a)-y)^2].$$
Every d_delay critic steps, optimize $L_\mu=-\mathbb E[Q_{w_1}(s,\mu_\theta(s))]$ and Polyak-update targets. The delay symbol here is not the terminal mask d. The actor usually uses Q1, not the minimum; follow the algorithm rather than making every twin operation a minimum by habit.

### A single transition, two estimates
With reward -1, gamma 0.99, and target critics [6, 4], the nonterminal target is $-1+0.99\cdot4=2.96$. Using the optimistic maximum gives 4.94 instead. If the transition is truly terminal, both collapse to -1.

If both critics overestimate the same action by two because their training data miss that region, their minimum is still wrong. The sketch's error-correlation control illustrates why diversity matters and why two networks do not guarantee coverage.


### Start from the weakness of a deterministic actor
DDPG learns an actor that maximizes a learned Q function. If the critic has a spurious peak, the actor has every incentive to find it. Executing the proposed action may reveal that it is poor, but bootstrapped learning can reinforce the mistaken estimate before enough correcting experience arrives. TD3 combines three interventions aimed at that feedback loop. They are complementary design choices, not a proof that estimation error disappears.

First, two online critics learn from the same replay and target; use the smaller of their target predictions for bootstrapping. Second, add small clipped noise to the target actor's command before evaluating continuation. This discourages target values supported only by an extremely narrow action peak. Third, update the actor less frequently than the critics, allowing additional value-fitting steps between policy changes. Correlated critics can still make correlated mistakes.

### Keep two different noises separate
Exploration noise is applied to actions executed by the behavior policy during data collection. It changes the experience stored in replay. Target-policy smoothing noise is sampled inside a detached Bellman target. It changes the continuation estimate used for critic regression. Neither noise is an entropy objective. TD3's learned policy remains deterministic, although its training-time behavior policy is noisy.

### Read the network and optimizer contract
The actor consumes observations [B,O] and returns bounded commands [B,A]. Each critic consumes observations and actions and returns [B]. There are target copies of both the actor and critics. A replay minibatch supplies stored commands, rewards, next observations and true-terminal flags. For the Franka A=7; the exact same update code accepts AgileX A=12 when all shapes are consistent.

Under no-grad, calculate the next target action, add target noise, clip to normalized limits, and evaluate the target critic minimum. Form the bootstrapped target and fit both online critics to it. Every second critic update in this implementation, freeze critic parameters and minimize negative Q1 evaluated at the current actor's action. Use Q1 for the policy gradient; the target minimum remains part of the critic target. The actor's gradient must traverse Q1's action input. Update the target actor and target critics only on these delayed steps.

### Work the target before running it
Take reward -0.1, gamma 0.99, and target predictions 4 and 6 after smoothing. The target is 3.86. Using only the optimistic critic gives 5.84. At true termination the target is -0.1 regardless of both critics. A 3.86 target is a regression label, not evidence that the robot will achieve that return: it inherits the accuracy and support of the bootstrapped estimates.

Set delay to 1, then remove smoothing, then replace the target minimum by Q1, one controlled change at a time. Keep reward, reset distribution, transition count and evaluation seeds fixed. Compare critic disagreement, evaluation return and action saturation. A single run can illustrate a failure; multiple training seeds are needed to claim a reliable algorithmic effect.

## A failure to watch for

Exploration noise and target smoothing are applied in different places for different purposes.

## Explain it back

Does taking the smaller of two critics guarantee a lower bound on the true Q?
